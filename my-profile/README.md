# My Profile

The `.toon` files in this directory represent mock customer data
consumed by the `lumen` CLI to produce personalised health
recommendations.

## Files

| File | Contents |
|----|----|
| `profile.toon` | Basic person attributes (name, age, sex, location, occupation) |
| `blood_tests.toon` | Blood panel results with 25 markers including reference ranges and status flags |
| `wearable_data.toon` | 30-day Oura Ring averages (sleep, HRV, resting heart rate, readiness, etc.) |

These files are intentionally simple mocks. Edit them as necessary to
add personalisation or test different scenarios.
